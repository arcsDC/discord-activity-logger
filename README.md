# discord-activity-logger

A Discord bot that logs member join, leave, and nickname changes to a configurable channel for community auditing.

## Stack

Primary language: **Python**

## Project structure

- `bot.py` — Log server membership and identity changes to a designated channel.
- `requirements.txt` — dependencies
- `tests/test_main.py` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
